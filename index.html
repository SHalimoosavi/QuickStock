The problem

Spreadsheets don't scale. Cloud subscriptions don't ask permission.

Most small operations end up choosing between two bad options: a spreadsheet that silently drifts out of sync across three people's laptops, or a SaaS platform that charges per seat, per warehouse, and stops working the moment your internet does.

Spreadsheet chaos

Duplicate SKUs, stale copies emailed back and forth, and no record of who changed what or when.

Cloud dependency

Lose your connection, lose your ability to make a sale. Warehouses and shop floors don't always have reliable Wi-Fi.

Expensive subscriptions

Per-seat, per-location SaaS pricing that keeps climbing as you grow — for software running someone else's server.

Inventory mismatches

Manual counts, manual entry, manual mistakes. Stock on the shelf never quite matches stock on the screen.

No audit trail

When something doesn't add up, there's no history to check — just a number, and no way to know how it got there.

Vendor lock-in

Your inventory data lives in someone else's database, in their export format, under their terms of service.

Everything a warehouse actually needs

One app. No add-ons to buy later.

Every feature below ships in the same install — nothing is gated behind a paid tier, because there isn't one.

📴

Offline-first & installable

Runs entirely on your own machine. Install it as a PWA on desktop or mobile; the app shell loads instantly and keeps working through a dropped connection.

📷

Barcode & QR scanning

Camera-based scanning with a manual-entry fallback that also works with any USB or Bluetooth barcode scanner. Generate and bulk-print QR labels for anything you don't already have a barcode for.

🏬

Multi-location inventory

Track stock per warehouse, store, or shelf. Transfer stock between locations with a full, undoable history — single-location use stays exactly as simple as it always was.

🧾

Suppliers & purchase orders

A real draft → ordered → received workflow. Receiving a purchase order restocks the right location automatically and logs it like any other restock.

📊

Import, export & reports

Bulk import or export via CSV or Excel with a dry-run preview before anything is written. Print-ready inventory, low-stock, and activity reports — no PDF library required.

🔐

Optional accounts & roles

Authentication is off by default. Turn it on when you need it, with two roles — staff and admin — so the front desk can record a sale without touching settings.

🔄

LAN & cloud sync

A sync peer is just a URL — a warehouse PC on your LAN or a remote instance work identically. Explicit, mutual pairing keeps you in control of who you sync with.

↺

Full history & undo

Every sale, dispatch, restock, adjustment, and transfer is logged permanently, with a one-click undo for the most recent action — undo and redo chain correctly, every time.

Under the hood

Technical architecture

Deliberately small and dependency-light — easy to read, easy to audit, easy to run anywhere Node.js runs.

Backend

Node.js + Express. REST API, atomic JSON storage, Helmet, rate limiting.

Frontend

Vanilla HTML, CSS, and JavaScript — no framework, no build step, no bundler.

Storage

Local JSON files with atomic writes, automatic timestamped backups, and corrupt-file recovery.

Offline layer

Service worker, Cache API, and IndexedDB for an installable Progressive Web App with a real offline write queue.

Sync protocol

Peer-to-peer HTTP with shared-secret pairing and last-write-wins conflict resolution — works over LAN or the internet identically.

CI/CD

GitHub Actions runs install, syntax, and boot checks on every push, across Node 18, 20, and 22.

Questions

Frequently asked questions

What is QuickStock Sync?

QuickStock Sync is a free, open-source, offline-first inventory management platform for warehouses, retail stores, and small businesses. It runs on your own machine using Node.js and Express, stores data in local JSON files, and includes barcode/QR scanning, multi-location stock tracking, purchase orders, CSV/Excel import and export, and optional LAN or cloud sync between instances.

Is QuickStock Sync open source?

Yes. QuickStock Sync is released under the MIT License. The full source code is available on GitHub at github.com/SHalimoosavi/SYJ-QuickStock-Sync.

Is QuickStock Sync free to use?

Yes, completely. There is no subscription, no paid tier, and no feature paywall. You install it yourself and run it on your own hardware.

Can QuickStock Sync work offline?

Yes. QuickStock Sync is offline-first by design. It's installable as a Progressive Web App, caches its own interface for instant loading, and queues stock operations (sale, dispatch, restock, adjustment, transfer) made while offline — automatically syncing them once the connection returns.

Does it support barcode scanning?

Yes. QuickStock Sync uses the browser's built-in camera-based barcode/QR scanner, with a manual-entry fallback that also works with any USB or Bluetooth barcode scanner, since those act like a keyboard.

Does it support QR code labels?

Yes. Every product can generate a printable QR label, individually or in bulk for a whole filtered view or a selected group of products — ready for label paper.

Does it support CSV import and export?

Yes. You can bulk import products from a CSV file, with a dry-run preview showing exactly what will change before anything is written, and export your full inventory to CSV at any time.

Does it support Excel import and export?

Yes. Excel (.xlsx) import and export work the same way as CSV, using the same dry-run preview before any bulk import is applied.

Does it support multiple warehouses or locations?

Yes. Stock is tracked per location. You can add as many locations as you need and transfer stock between them, with a full, undoable history for every transfer. Single-location use is unaffected — the location picker only appears once you actually add a second one.

Does it support suppliers?

Yes. You can manage a list of suppliers and link purchase orders to them.

Does it support purchase orders?

Yes. Purchase orders follow a full draft → ordered → partially received → received (or cancelled) workflow. Receiving items restocks the correct location automatically and logs it in the same activity history as a manual restock.

Does it support user authentication?

Yes, and it's optional. Authentication is off by default so a single user can start immediately with no login. When you're ready, you can enable it and create accounts with one of two roles: staff (record stock operations) or admin (full access, including settings and user management).

Does it support LAN synchronization?

Yes. Two QuickStock Sync instances on the same local network can sync inventory, history, locations, and suppliers with each other using an explicit, secret-paired connection.

Does it support cloud synchronization?

Yes — LAN sync and cloud sync are the same feature. A sync peer is just a URL, so pointing at a remote or cloud-hosted instance works identically to pointing at a machine on your local network.

Is QuickStock Sync a Progressive Web App?

Yes. It has a web app manifest, a full icon set, and a service worker, so it can be installed to a desktop or phone home screen and launched like a native app.

What technology is QuickStock Sync built with?

The backend is Node.js and Express. The frontend is vanilla HTML, CSS, and JavaScript — no framework, no build step. Data is stored in local JSON files with atomic writes and automatic backups.

Does it require a database like MySQL or MongoDB?

No. QuickStock Sync stores everything in local JSON files with atomic writes, automatic timestamped backups, and recovery from corrupted files — no separate database server to install or manage.

Can I self-host QuickStock Sync?

Yes — self-hosting is the only way it runs. Clone the repository, run npm install and npm start, and it's live on your own machine or server.

Who is QuickStock Sync for?

Warehouse teams, retail stores, distributors, independent vendors, and any small or growing business that needs real inventory control without paying for enterprise software.

Does it support dark mode?

Yes, with a per-browser toggle and a configurable default theme in Settings.

Does it support undo?

Yes. The most recent stock action can be undone with one click, and undo/redo chains correctly even across a stock transfer between locations.

How do I install QuickStock Sync?

Requires Node.js 18 or later. Run:

git clone https://github.com/SHalimoosavi/SYJ-QuickStock-Sync.git
cd SYJ-QuickStock-Sync
npm install
npm start

The server starts on http://localhost:3000 by default.

What license is QuickStock Sync released under?

The MIT License — free to use, modify, and self-host, including for commercial purposes.

Who created QuickStock Sync?

QuickStock Sync was built by Syed Ali Hasan Moosavi, Founder & Managing Director of SAYANJALI NEXUS PRIVATE LIMITED, an AI engineer and full-stack developer building open-source developer tools and automation platforms.

Does QuickStock Sync send my data anywhere?

No, not unless you explicitly configure a sync peer yourself. By default, all data stays in local JSON files on the machine running the app — there's no telemetry and no external service it talks to on its own.
