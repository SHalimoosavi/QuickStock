# QuickStock Sync — Landing Page

The marketing/landing website for **[QuickStock Sync](https://github.com/SHalimoosavi/SYJ-QuickStock-Sync)** — a free, open-source, offline-first inventory management platform.

**Live site:** https://shalimoosavi.github.io/QuickStock/
**App repository:** https://github.com/SHalimoosavi/SYJ-QuickStock-Sync

## About

This is a completely static site — plain HTML, CSS, and JavaScript, no build step, no framework, no dependencies. It's designed to be hosted directly on GitHub Pages from this repository.

It covers the product's features, architecture, version history, a spreadsheet/SaaS/QuickStock comparison, 25 FAQs written for both human readers and AI answer engines, and information about the developer and other open-source projects.

## Structure

```
.
├── index.html                  # The entire site (single page)
├── 404.html                    # Custom not-found page
├── css/styles.css              # All styles
├── js/script.js                # Scroll reveals, counters, mobile nav, live GitHub star count
├── icons/                      # Favicons, PWA icons, OG banner — generated by generate-icons.js
├── generate-icons.js           # Regenerates the icon set (pure Node, no dependencies)
├── manifest.webmanifest        # Web app manifest
├── browserconfig.xml           # Windows tile config
├── robots.txt
├── sitemap.xml
├── structured-data.json        # Reference copy of the JSON-LD schemas embedded in index.html
└── .github/workflows/pages.yml # Deploys to GitHub Pages on every push to main
```

## Local preview

No build step — just serve the folder. For example:

```bash
npx serve .
# or
python3 -m http.server 8080
```

Then open the printed local URL in your browser.

## Deployment

Pushing to `main` triggers `.github/workflows/pages.yml`, which deploys the repository directly to GitHub Pages. In the repository's **Settings → Pages**, set the source to **GitHub Actions**.

## Regenerating icons

The icon set is generated with nothing but Node's built-in `zlib` — no image library, no network access needed:

```bash
node generate-icons.js
```

## SEO / AEO / GEO

- Full meta tags, canonical URL, Open Graph, and Twitter Card tags
- JSON-LD structured data: `Organization`, `SoftwareApplication`, `WebSite` + `SearchAction`, `BreadcrumbList`, and `FAQPage`
- `robots.txt` and `sitemap.xml`
- 25 FAQ entries written as direct, self-contained answers so they're easy for both search engines and AI answer engines (ChatGPT, Claude, Gemini, Perplexity) to extract and cite
